Helmsman voyage flow

From a task in your selected galleon to an approved commit, a published PR, and follow-up reviews.

  • 2 desired reviewer CLIs
  • 3 review rounds
  • 45 min per agent session

Defaults shown; live configuration may differ. Mermaid source and full notes · Works offline · Print or save as PDF from your browser.

Review selection and concurrency

The writer CLI is required. If the alternate CLI is unavailable, one reviewer is allowed even when two are configured. Lead sessions run sequentially; prompts request concurrent focused sub-agents, but runtime does not verify delegation.

Round and session limits

Configuration allows 1–2 reviewers, 1–5 rounds, and 5–180 minutes per session. Summary correction gets one separate session per report and does not use another review round. The 2,000-character limit uses JavaScript string length, including whitespace and bylines.

Resume preserved work

A valid checkpoint skips implementation and reuses the original reports for its saved review round. The current branch, base, head, and complete reviewer set must match. Oversized saved summaries can use the same correction step.

Publication and follow-up boundaries

Pre-PR voyages have one outer attempt. Failures preserve work; a push may already have happened if a later publication check fails. Jira transitions apply to eligible Jira tasks, not todos or freeform tasks. The separate Helmsman review waits for availability and may reuse an existing review of the current head.
